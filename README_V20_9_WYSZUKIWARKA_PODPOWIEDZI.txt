AGROMARBANKA panel v20.9 — poprawka wyszukiwarki kontrahenta w raportach

Zmiany:
- w raportach wyszukiwarka kontrahenta pokazuje od razu listę podpowiedzi,
- nie trzeba już rozwijać zwykłej listy,
- po wpisaniu np. "ko" pojawia się lista kontrahentów do kliknięcia,
- jest przycisk "Wszyscy kontrahenci",
- nie trzeba wykonywać żadnego SQL w Supabase.

Wgranie:
1. Rozpakuj paczkę v20.9.
2. W GitHub repo agromarbanka-panel kliknij Add file → Upload files.
3. Wgraj zawartość paczki, czyli pliki/foldery widoczne w środku: public, src, index.html, package.json itd.
4. Commit changes.
5. Poczekaj na deploy Vercel.
6. Otwórz aplikację i zrób CTRL+SHIFT+R albo CTRL+F5.
