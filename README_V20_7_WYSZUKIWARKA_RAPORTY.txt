AGROMARBANKA panel v20.7 — wyszukiwarka kontrahenta w raportach

Zmiany:
- dodano wyszukiwarkę przy wyborze kontrahenta w raportach,
- wpisujesz fragment nazwy i lista kontrahentów zawęża się automatycznie,
- zostaje opcja „Wszyscy kontrahenci”,
- nie trzeba wykonywać żadnego SQL w Supabase.

Wgranie:
1. Rozpakuj paczkę.
2. W GitHub repo agromarbanka-panel kliknij Add file → Upload files.
3. Wgraj wszystkie pliki z rozpakowanej paczki.
4. Commit changes.
5. Poczekaj na deploy Vercel.
6. Otwórz aplikację i zrób CTRL+F5.
